# 方块学园 · 平板本地版

卡通养成主题的家庭学习工作台，含小学一至六年级与幼儿园学习入口、每日运动、伙伴成长、家园升级和积分奖励。

## 使用

从 `./tablet/` 进入。首次联网打开后，可添加到平板或手机主屏幕。建议先添加到主屏幕，再从桌面入口创建家庭。

- 家长自行创建三个孩子的角色与账号，可选择男孩或女孩形象。
- 本机记住上次的孩子，点击头像可以切换；家长管理需要密码。
- 账号校验信息、学习记录和进度保存在访问设备本地，不会自动同步到其他设备。可在家长中心导出/导入备份。
- 更换域名后，旧存档不会自动迁移，需要先从旧入口导出备份。

本仓库仅包含网站公开分发文件，不包含真实账号、密码、家庭学习记录、服务端数据库或访问密钥。

## 森林冒险与声音

- 首页直接显示自己的森林冒险角色和当前阶段的伙伴，分别可进入换装与陪伴。
- 大字模式、更大的触控按钮，平板学习任务改为宽松布局。
- 原创轻音乐，首次触摸页面后开启，可单独关闭；读题时自动降低音乐音量。
- 内置静态题目的普通话语音；幼儿颜色、形状与数量题采用大图片选答案，可反复听题。自定义文字的朗读取决于设备是否提供本地中文语音。
- 首次使用和更新时保持联网，让离线资源准备完成；更新不改变本机家庭存档的存储键。

声音素材与模型许可见 [tablet/audio/ATTRIBUTION.md](tablet/audio/ATTRIBUTION.md)。角色为原创森林冒险形象。
